Deployment guide

Get from browser to a dedicated tablet hub in under five minutes.

01　Install the PWA

Open this hub in Chrome on Android Tablet or Safari on iPad. Choose Add to Home Screen to launch it as a standalone app.

02　Pair the watch

Wake your Redmi Watch Move, open Settings → Connectivity → Bluetooth, then choose Pair new device. The hub requests GATT access through Web Bluetooth.

03　Map the crown shortcut

In the Xiaomi wearable companion app, set the rotating crown long-press to Voice capture. Short press rotates between Pet, Face Studio, and Vitality modes.

04　Connect WhatsApp

Add your destination number with a country code. When a task completes, the hub prepares a prefilled wa.me message.
